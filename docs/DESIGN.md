# Design

## UI Principles

- Dense, scannable, work-focused interface.
- Thumbnail cards should support fast comparison.
- Modal chart view should prioritize the chart and essential metadata.
- Controls should use familiar inputs, icon buttons, and restrained visual styling.

## Current Visual Model

- Light workspace background.
- Sidebar navigation.
- Card grid for repeated chart thumbnails.
- Full-width modal for detailed chart interaction.

## Requirements For UI Changes

- Keep text within containers at desktop and mobile widths.
- Do not add marketing-style hero sections.
- Do not render heavy chart components in repeated grid items.
- Add screenshot or browser evidence when changing layout-critical UI.
