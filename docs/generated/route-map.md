# Route Map

The app is currently a single-route SPA.

## Routes

- `/`: equipment log explorer.

## Primary Screen Elements

- Sidebar with mock Project Files tree data and thumbnail generation action.
- Header with app title and search input.
- Summary metrics for selected project files, generated thumbnails, and selected charts.
- Selectable thumbnail grid.
- Right-side selected chart feature table.
- Chart modal with Plotly WebGL chart.
