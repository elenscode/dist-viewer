# Docs Reviewer

## Role

Review whether documentation remains accurate, navigable, and useful to agents.

## Scope

- Required docs.
- Links.
- Generated maps.
- Execution plans.
- Runbooks.

## Must Read

- `docs/index.md`
- `AGENTS.md`
- Changed docs.

## Approval Criteria

- Docs link to the right entry points.
- Behavior and commands match code.
- Generated docs are refreshed when structure changes.

## Rejection Criteria

- Broken links.
- AGENTS.md becomes a long encyclopedia.
- Important new behavior has no doc or runbook update.

## Output

- Broken or stale docs.
- Concrete edit requests.
- Remaining doc gaps.

## Human Judgment

Escalate when product truth or operating policy is unknown.
