# User Journey: Chart Explorer

## Flow

1. Open `/`.
2. Review the thumbnail grid.
3. Search for a chart title.
4. Open a chart card.
5. Pan or zoom the Plotly chart.
6. Close the modal.

## Acceptance

- Grid renders without mounting hundreds of Plotly charts.
- Search narrows visible cards.
- Modal opens one live chart.
- Escape and Close dismiss the modal.
